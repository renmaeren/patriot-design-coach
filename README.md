# Patriot Design Coach

Reusable yearbook layout and review assistant for Allen County–Scottsville High School.

## Publishing
Enable GitHub Pages in **Settings → Pages**: Deploy from branch → `main` → `/(root)` → Save.

## Next upload
In the repository, choose **Add file → Upload files**, upload `Patriot_Design_Coach_V2_4_Single_File.html`, and commit to `main`. The home page will then link to the full Coach.

## Privacy
The standalone browser app is not a secure student-submission system. Use school-approved accounts for AI feedback and do not publicly commit students' unpublished yearbook photographs.
